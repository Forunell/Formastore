# QA — FormaStore

Дата проверки: **03.11.2026**. Среда: Windows, Node.js 24.22.2, локальный Vite, установленный Microsoft Edge через Playwright. Все примеры вымышленные.

## Фактически выполненные команды

| Проверка | Статус | Результат |
| --- | --- | --- |
| `npm.cmd install` | PASS | 212 локальных пакетов, создан lockfile |
| `npm.cmd run build` | PASS | TypeScript + production-сборка Vite |
| `npm.cmd run lint` | PASS | ESLint без ошибок и предупреждений |
| `npm.cmd test` | PASS | 16 unit-тестов, 1 файл |
| `npm.cmd run test:e2e` | PASS | Финальный прогон: 10/10 тестов, 21.7 с |
| `START.cmd` + HTTP-проверка | PASS | Vite запущен через пользовательский launcher, главная вернула HTTP 200 |

Первый браузерный прогон выявил 4 ошибки ожидания радиокнопки фильтра: React Router завершал обновление URL после мгновенной проверки `check()`. Состояние самой страницы обновлялось правильно. Тест изменён на пользовательский `click()` и отдельную ожидающую проверку `toBeChecked()`; количество и содержимое результатов также проверяются. Финальный полный прогон прошёл без повторных попыток. На Windows первый процесс тестов задержался при остановке Vite; повторный запуск использовал уже работающий сервер.

## Пять ручных проверок для владельца

1. В каталоге найти `Лампа Arc`, затем `zzzzz`; сбросить поиск и совместить категорию с ценой 2000–2800.
2. Добавить Arc и Rise, увеличить Arc до двух: сумма 6 670 ₴. Перезагрузить страницу, уменьшить количество и удалить позиции.
3. Открыть `/products/fold`, добавить два разных цвета; убедиться, что третий экземпляр недоступен. У Line кнопка также отключена.
4. Сохранить товар сердечком, открыть обране, перезагрузить и удалить его.
5. При ширине 360 px открыть меню и фильтры, добавить Arc. В оформлении сначала отправить пустую форму, затем заполнить фиктивный пример и скачать демоквитанцию.
