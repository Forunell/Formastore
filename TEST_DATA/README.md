# Вымышленные тестовые данные

`checkout.json` — пример для ручного ввода в форму; загрузка файла в приложение не требуется. Реальный телефон, email и адрес не используются.

| Пример | Ожидаемый результат |
| --- | --- |
| Arc × 1 + Rise × 1 | 4 180 ₴ |
| Arc × 2 + Rise × 1 | 6 670 ₴ |
| Arc × 1 + демокурьер | 2 580 ₴, реальная оплата 0 ₴ |
| Fold в любом сочетании цветов | Всего не больше 2 шт. |
| Line или Plain | Остаток 0, добавление недоступно |
| Освещение, 2000–2800 ₴ | Arc, Halo, Line |
| Поиск `Лампа Arc` | 1 результат |
| Поиск `zzzzz` | 0 результатов |
| Имя из пробелов | Ошибка валидации |

Для проверки восстановления можно временно записать в DevTools → Application → Local Storage ключ `forma-cart-v1` со значением `{broken`, затем перезагрузить страницу. Приложение покажет сообщение и создаст новый пустой кошик. Делайте это только на локальном демосайте.
